### Date

### Security Update

V1.9.4 is a security update to V1.9.2. It contains no functional changes: the API, the configuration files and the license handling are the same as in V1.9.2, so it can replace a V1.9.2 installation in place.

* __gRPC-Go v1.83.2__ (device gateway, master gateway, Go client SDK)
  - CVE-2026-84304 (High): an HTTP/2 peer could exhaust the gateway's heap by splitting DATA frames. The gateway accepts connections before authentication, so this one was reachable; it is fixed.
  - CVE-2026-84445 (High) and CVE-2026-84303 (Medium): xDS server and xDS RBAC filter issues. The gateways do not use xDS; closed by the same upgrade.
* __Go 1.26.9 toolchain and golang.org/x/net v0.60.0__ (all Go binaries rebuilt)
  - Closes the Go advisories published on 2026-10-12: CVE-2026-78663, CVE-2026-78659, CVE-2026-78669, CVE-2026-78660, CVE-2026-97032 (HTTP/2 in x/net and net/http), CVE-2026-56857 (os.Root on Windows), CVE-2026-56866, CVE-2026-94439, CVE-2026-78667, CVE-2026-94440 (net/http, mime/multipart), CVE-2026-97031 (crypto/tls ECH), CVE-2026-94448 and CVE-2026-97030 (html/template).
  - The gateways use neither net/http nor the x/net HTTP/2 server and client (gRPC-Go has its own HTTP/2 transport), and do not enable ECH, so none of these were reachable through the gateway. They are closed by the rebuild so that the shipped binaries carry no known vulnerability.
* __Node client SDK__
  - `@grpc/grpc-js` ^1.14.5: CVE-2026-101916 (High) and CVE-2026-101915 (Low) affect the gRPC server side only, which the SDK does not use.
  - `moment` ^2.31.0: CVE-2026-17495 (Medium), path traversal through a non-string `locale()` argument. The SDK does not pass user input to `locale()`.

### Security and CRA

* As with every release, the package ships a CycloneDX SBOM, a Grype vulnerability report (zero known matches at packaging time), `SECURITY.md` and per-archive `SHA256SUMS.txt` checksums.
* To report a vulnerability, see `SECURITY.md` in the package or on the repository.

### SDK License Agreement

* Unchanged from V1.9.2: the SDK License Agreement file (**"LICENSE_AGREEMENT.txt"**) must be in the current working directory before running device_gateway. Create it by renaming the file (**"LICENSE.txt"**) distributed with [the SDK package](https://download.supremainc.com/download-center/pages/login.asp).
